# McDonald's Data Analysis

## Project Overview
This project analyzes McDonald's menu data using Python to explore nutritional information and identify useful patterns.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The dataset contains nutritional information about McDonald's menu items.

## Analysis
The project includes:
- Data cleaning
- Exploratory Data Analysis (EDA)
- Calorie analysis
- Fat and nutrition analysis
- Data visualization
- Key findings

## Project Files
- Jupyter Notebook (.ipynb) — Complete data analysis
- CSV file — Dataset
- README.md — Project documentation

## Conclusion
This project demonstrates the use of Python for data cleaning, analysis, visualization, and extracting useful insights from a real-world dataset.
